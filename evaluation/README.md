# 智能方法评估数据集与测试方案

## 一、评估数据集构建

### 1.1 数据集概述

本项目构建了针对医院就诊智能体系统的多模态评估数据集,包含以下三个核心模块的测试数据:

#### 1.1.1 手语识别模块数据集
- **数据来源**: 围绕急诊医学词汇采集的视频,经MediaPipe提取为骨架关键点序列
- **数据规模**: 13,289个骨架序列样本
- **类别数量**: 66个医学词汇类别
- **数据格式**: 每帧258维特征(33个姿态关键点×4 + 21个左手关键点×3 + 21个右手关键点×3)
- **标注信息**: label_mapping.json包含66个医学词汇到类别ID的映射

#### 1.1.2 智能分诊Agent数据集
- **数据规模**: 200个测试样本
- **数据类别**:
  - 明确症状描述(50样本): 症状+部位+时长完整
  - 模糊症状描述(50样本): 仅部分信息
  - 多轮对话场景(50样本): 需要追问补全信息
  - 边界异常情况(50样本): 换科室、取消、重新描述等
- **标注内容**: 期望的科室推荐、槽位提取结果、对话策略

#### 1.1.3 面诊同传Agent数据集
- **数据规模**: 150个测试样本
- **数据类别**:
  - 手语词汇翻译(50样本): 离散词汇组合
  - 上下文理解(50样本): 需结合对话历史
  - 长期记忆调用(50样本): 需引用患者历史病情
- **标注内容**: 期望的润色文本、病历摘要

### 1.2 数据集划分

```
总数据集: 13,639个样本
├── 手语识别: 13,289个样本
│   ├── 训练集: 10,631个 (80%)
│   ├── 验证集: 1,329个 (10%)
│   └── 测试集: 1,329个 (10%)
├── 智能分诊Agent: 200个样本
│   ├── 开发集: 140个 (70%)
│   └── 测试集: 60个 (30%)
└── 面诊同传Agent: 150个样本
    ├── 开发集: 105个 (70%)
    └── 测试集: 45个 (30%)
```

## 二、评价方法

### 2.1 手语识别模块评价方法

#### 2.1.1 离线评估
- **方法**: 在测试集上进行批量推理,计算分类指标
- **流程**:
  1. 加载训练好的模型权重
  2. 遍历测试集样本
  3. 对每个样本进行前向推理
  4. 记录预测结果与真实标签
  5. 计算评价指标

#### 2.1.2 在线评估
- **方法**: 模拟真实使用场景,通过API接口进行实时识别测试
- **流程**:
  1. 启动后端服务
  2. 通过POST /api/sign/recognize接口发送关键点数据
  3. 记录识别结果和响应时间
  4. 统计成功率和平均延迟

### 2.2 智能分诊Agent评价方法

#### 2.2.1 槽位提取准确性评估
- **方法**: 对比Agent提取的槽位与标注的真实槽位
- **流程**:
  1. 输入测试样本的用户描述
  2. 调用Agent的triage_stage_understand方法
  3. 提取返回的symptom_struct和department
  4. 与标注进行对比,计算准确率

#### 2.2.2 对话策略合理性评估
- **方法**: 评估Agent在多轮对话中的追问策略是否合理
- **流程**:
  1. 模拟多轮对话场景
  2. 记录Agent每轮的响应和追问内容
  3. 人工评估追问是否必要、是否重复、是否遗漏关键信息
  4. 计算对话效率(平均轮次)和用户满意度

### 2.3 面诊同传Agent评价方法

#### 2.3.1 翻译质量评估
- **方法**: 对比Agent润色后的文本与参考翻译
- **流程**:
  1. 输入手语词汇序列和上下文
  2. 调用Agent的consultation_stage_polish方法
  3. 获取polished_text
  4. 使用BLEU、ROUGE等指标与参考翻译对比

#### 2.3.2 长期记忆调用评估
- **方法**: 评估Agent是否正确利用患者历史信息
- **流程**:
  1. 构造包含历史病情的患者画像
  2. 输入模糊表述(如"老毛病又犯了")
  3. 检查Agent是否从画像中提取正确的历史信息
  4. 计算记忆调用准确率

## 三、评价指标

### 3.1 手语识别模块指标

#### 3.1.1 分类性能指标
- **Top-1准确率(Accuracy)**: 预测类别与真实类别完全匹配的比例
  ```
  Accuracy = (正确预测样本数) / (总样本数)
  ```
- **Top-5准确率**: 真实类别在预测概率前5名中的比例
- **精确率(Precision)**: 针对每个类别,预测为该类别的样本中真正属于该类别的比例
- **召回率(Recall)**: 针对每个类别,真正属于该类别的样本中被正确预测的比例
- **F1分数**: 精确率和召回率的调和平均
  ```
  F1 = 2 * (Precision * Recall) / (Precision + Recall)
  ```
- **混淆矩阵**: 展示各类别之间的混淆情况

#### 3.1.2 鲁棒性指标
- **关键点缺失容忍度**: 随机遮挡部分关键点后的准确率下降幅度
- **速度变化容忍度**: 对不同手语速度的识别稳定性
- **跨人泛化能力**: 在未见过的手语者上的准确率

#### 3.1.3 效率指标
- **推理延迟**: 单个样本的平均推理时间(ms)
- **吞吐量**: 每秒可处理的样本数(FPS)
- **模型大小**: 模型参数量和存储空间

### 3.2 智能分诊Agent指标

#### 3.2.1 槽位提取指标
- **槽位准确率**: 每个槽位(症状、部位、时长、科室)的提取准确率
  ```
  槽位准确率 = (正确提取的槽位数) / (总槽位数)
  ```
- **完整槽位匹配率**: 所有槽位都正确提取的样本比例
- **科室推荐准确率**: 推荐科室与标注科室一致的比例

#### 3.2.2 对话效率指标
- **平均对话轮次**: 完成挂号所需的平均交互轮数
- **信息收集完整度**: 收集到的关键信息占比
- **重复追问率**: 对同一信息重复询问的比例

#### 3.2.3 鲁棒性指标
- **模糊输入处理能力**: 对不完整、口语化输入的理解准确率
- **意图识别准确率**: 正确识别用户意图(挂号、换科室、取消等)的比例
- **异常处理成功率**: 对边界情况的正确处理比例

### 3.3 面诊同传Agent指标

#### 3.3.1 翻译质量指标
- **BLEU分数**: 机器翻译质量评估指标,衡量与参考翻译的n-gram重叠度
- **ROUGE分数**: 召回导向的评估指标,衡量关键信息覆盖度
- **语义相似度**: 使用句向量计算与参考翻译的余弦相似度
- **人工评分**: 流畅性(1-5分)、准确性(1-5分)、完整性(1-5分)

#### 3.3.2 上下文理解指标
- **上下文一致性**: 翻译是否与对话历史保持一致
- **代词消解准确率**: 正确理解"它"、"这个"等指代的比例
- **省略补全准确率**: 正确补全省略信息的比例

#### 3.3.3 长期记忆指标
- **记忆调用准确率**: 正确引用患者历史信息的比例
- **记忆更新准确率**: 新信息正确融入长期记忆的比例
- **记忆一致性**: 多次就诊间记忆的一致性

## 五、测试数据集生成说明

本项目提供自动化脚本生成测试数据集:

1. **手语识别测试集**: 从训练数据中按8:1:1划分
2. **Agent测试集**: 基于真实场景模板生成,包含多样化的表述方式
3. **标注文件**: JSON格式,包含输入、期望输出、评估标准

详见 `generate_test_dataset.py` 和 `evaluation_test.py`
