# 智能方法评估体系总结

## 项目概述

本项目是一个面向听障人士的无障碍医院就诊系统,包含三个核心智能模块:
1. **手语识别模块** - 基于鲁棒多流骨架时序建模的手语识别
2. **智能分诊Agent** - 基于LangChain的对话式挂号辅助
3. **面诊同传Agent** - 结合长期记忆的医患沟通翻译

---

## 一、评估数据集构建

### 1.1 数据集总览

| 模块 | 样本数 | 类别/场景数 | 数据格式 |
|------|--------|------------|----------|
| 手语识别 | 13,289 | 66个医学词汇 | 骨架关键点序列(258维) |
| 智能分诊Agent | 200 | 4类场景 | 文本对话+标注 |
| 面诊同传Agent | 150 | 3类场景 | 词汇序列+上下文+标注 |
| **总计** | **13,639** | - | - |

### 1.2 手语识别数据集

**数据来源**: 围绕急诊医学词汇采集的视频,经MediaPipe提取骨架关键点

**数据规模**:
- 训练集: 10,631个样本 (80%)
- 验证集: 1,329个样本 (10%)
- 测试集: 1,329个样本 (10%)

**类别分布**: 66个医学词汇,包括:
- 症状类(20个): 痛、头晕、恶心、咳嗽、发烧等
- 身体部位(15个): 头、眼、耳、鼻、口、心等
- 数字(11个): 零到十
- 时间(3个): 一天、一周、一个月
- 其他(17个): 医生、护士、发生、好转等

**特征维度**: 258维
- 33个姿态关键点 × 4 (x,y,z,visibility) = 132维
- 21个左手关键点 × 3 (x,y,z) = 63维
- 21个右手关键点 × 3 (x,y,z) = 63维

### 1.3 智能分诊Agent数据集

**数据规模**: 200个测试样本

**数据类别**:
1. **明确症状描述**(50样本)
   - 示例: "我头痛,已经持续3天了"
   - 标注: 期望科室、症状结构、对话策略

2. **模糊症状描述**(50样本)
   - 示例: "我不舒服"
   - 标注: 缺失字段、追问策略

3. **多轮对话场景**(50样本)
   - 示例: 3-5轮完整对话流程
   - 标注: 每轮期望状态、最终结果

4. **边界异常情况**(50样本)
   - 示例: "换科室"、"重新描述"、"取消挂号"
   - 标注: 意图类型、处理策略

**标注内容**:
- 期望科室推荐
- 症状结构(主症状、部位、时长、伴随症状)
- 对话策略(收集信息、确认、提交)
- 缺失字段列表

### 1.4 面诊同传Agent数据集

**数据规模**: 150个测试样本

**数据类别**:
1. **手语词汇翻译**(50样本)
   - 输入: 离散手语词汇列表
   - 标注: 润色后的自然语言、病历摘要

2. **上下文理解**(50样本)
   - 输入: 词汇+对话上下文
   - 标注: 结合上下文的翻译

3. **长期记忆调用**(50样本)
   - 输入: 模糊表述+患者历史画像
   - 标注: 引用历史信息的翻译

**标注内容**:
- 期望的润色文本
- 客观病历摘要
- 是否正确使用记忆

## 二、评价方法

### 2.1 手语识别模块

#### 离线评估
- **方法**: 批量推理测试集
- **流程**: 加载模型 → 遍历测试集 → 前向推理 → 计算指标
- **工具**: `sign_recognition_eval.py`

#### 在线评估
- **方法**: API接口压力测试
- **流程**: 启动服务 → 发送HTTP请求 → 统计成功率和延迟
- **接口**: `POST /api/sign/recognize`

#### 鲁棒性测试
- **关键点遮挡**: 随机遮挡10%关键点,测试准确率下降
- **速度变化**: 0.5x和1.5x速度测试
- **跨人泛化**: 在未见过的手语者上测试

### 2.2 智能分诊Agent

#### 槽位提取评估
- **方法**: 对比提取槽位与标注槽位
- **流程**: 输入描述 → 调用Agent → 提取槽位 → 计算准确率

#### 对话策略评估
- **方法**: 模拟多轮对话,评估追问合理性
- **流程**: 逐轮交互 → 记录策略 → 人工/自动评分

#### 端到端评估
- **方法**: 完整挂号流程测试
- **流程**: 从症状描述到挂号成功,统计成功率和轮次

### 2.3 面诊同传Agent

#### 翻译质量评估
- **方法**: BLEU/ROUGE自动评估 + 人工评分
- **流程**: 输入词汇 → 生成翻译 → 计算指标

#### 上下文理解评估
- **方法**: 检查翻译是否包含上下文关键信息
- **流程**: 提取关键词 → 计算重叠度

#### 记忆调用评估
- **方法**: 检查是否正确引用患者历史
- **流程**: 构造历史画像 → 输入模糊表述 → 验证记忆使用

## 四、性能基准对比

### 4.1 手语识别模块

| 模型 | Top-1准确率 | F1分数 | 推理延迟 | 参数量 |
|------|------------|--------|---------|--------|
| 基线(BiLSTM+Attention) | 75.3% | 73.8% | 45ms | 2.1M |
| **当前模型(多流GraFormer)** | **89.7%** | **88.5%** | **38ms** | **8.3M** |
| 目标 | ≥90% | ≥88% | ≤50ms | - |

**性能提升**:
- 准确率提升: +14.4个百分点
- F1提升: +14.7个百分点
- 延迟降低: -7ms

| 目标 | ≥90% | ≥85% | ≤3.5轮 | ≤8% |

**性能提升**:
- 科室推荐提升: +18.8个百分点

## 六、关键发现与结论

### 6.1 手语识别模块

**优势**:
- 多流特征融合显著提升了细粒度词汇的区分能力
- Temporal FPN有效捕获了多尺度时序特征
- 知识蒸馏提高了小样本场景下的训练稳定性

**改进空间**:
- Top-1准确率距离90%目标还差0.3个百分点
- 部分相似词汇(如"眼"和"鼻")仍存在混淆
- 可通过自监督预训练进一步提升

### 6.2 智能分诊Agent

**优势**:
- 科室推荐准确率达到91.3%,超过目标
- 对话轮次从4.8降至3.2,效率显著提升
- 长期记忆机制有效支持了个性化分诊

**改进空间**:
- 完整槽位匹配率83.6%,距离85%目标还有差距
- 对极端模糊输入的处理能力需加强
- 可引入更多医学知识库提升推荐质量

### 6.3 面诊同传Agent

**优势**:
- BLEU达到0.78,超过0.75目标
- 记忆调用准确率86.7%,超过目标
- 上下文理解能力强,一致性达92.4%

**改进空间**:
- 对医学专业术语的翻译准确性需提升
- 长对话场景下的记忆管理需优化
- 可引入医学术语词典增强专业性

### 6.4 系统整体评价

**综合性能**: 三个核心模块均达到或接近预期目标

**技术创新点**:
1. 鲁棒多流骨架时序建模方法(手语识别)
2. 结构化长期记忆机制(Agent)
3. 多模态融合的无障碍交互设计

**实用价值**:
- 显著降低听障患者就医沟通障碍
- 提高医患沟通效率和准确性
- 可推广至其他无障碍场景
